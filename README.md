## ISSAC orginal code

note:  All the functions of ISSAC were integrated including single-cell level junctions extraction, site-based splice event quantification, null binomial model construction, score tests for cis- & trans- sQTL mapping and differential splicing analysis.
junctions_extract.cpp & junctions_extract.h were reformed from regtools (https://github.com/griffithlab/regtools) to enable junctions extraction at the single-cell level.
